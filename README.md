# 保羅助理團隊

「保羅」是一組 Claude Code 子代理（subagents）團隊，讓你丟出**一個詞、短語或主題**，就能從多個角度發想出一整片內容——命名、文案、詩、故事、成語典故，最後由評審策展人整理出精華版。

## 團隊成員

| 代理 | 角色 | 說明 |
| --- | --- | --- |
| `paul` | 總召集人 | 拆解任務、分派給下列專家，並彙整成一份結構化的「森林報告」 |
| `namer` | 命名師 | 發想品牌、產品、角色命名 |
| `copywriter` | 文案家 | 發想標語、廣告文案、社群貼文 |
| `poet` | 詩人 | 以種子詞為題創作短詩（現代詩／仿古典／極短詩） |
| `storyteller` | 故事家 | 把種子詞擴寫成極短篇故事或寓言 |
| `idiom-scholar` | 成語典故家 | 找出相關成語、典故、諧音、雙關 |
| `critic-curator` | 評審策展人 | 從所有產出中挑選精華，給出使用建議 |

代理定義檔位於 [`.claude/agents/`](.claude/agents)。

## 使用方式

**完整發想**：直接請 Claude Code 呼叫 `paul`，並給出一個詞或主題，例如：

> 用「保羅」團隊幫我發想「潮汐」這個詞

總召集人會視需要並行呼叫命名師、文案家、詩人、故事家、成語典故家，再交由評審策展人整理精華，最後彙整成一份分類清楚的報告。

**單一專家**：也可以直接指名單一代理，只要其中一種產出，例如只要標語就直接呼叫 `copywriter`。

## 設計原則

- 每位專家職責單一、互不重疊，避免產出內容雷同或角色混亂。
- 總召集人只負責統籌與彙整，不自行創作，確保分工清楚。
- 各代理在系統提示中都內建品質與倫理界線（例如避免侵權命名、避免誇大不實文案、避免血腥暴力故事、成語出處不確定時誠實標註），降低發想過程中出錯或失控的風險。
